# Системное программирование в Linux

Репозиторий содержит выполненные проекты и практические задачи в рамках обучения в школе Eltex. Структура разделена по ключевым блокам обучения.

---

## Стек технологий
* **Язык программирования:** C (Си)
* **Сборка проекта:** GCC, GNU Make
* **Среда развертывания:** Docker, Docker Compose
* **Автоматизация:** Bash

---

## Структура и темы практических задач

## Выпускные проекты
* 📁 **[driver_manager_ipc_app](./driver_manager_ipc_app) - Система управления водителями такси (CLI):**
  * Разработка консольного приложения-диспетчера для динамического создания дочерних процессов (водителей) через системные вызовы Linux.
  * Реализация логики отслеживания состояний (Available/Busy) и распределения задач между независимыми процессами по их PID.
* 📁 **[raw_sockets_app](./raw_sockets_app) - Эхо-сервер и эхо-клиент на raw-сокетах:**
  * Написание клиента и сервера на протоколе UDP с использованием raw сокетов и ручным формированием сетевых заголовков.
  * Реализация хранения состояний на сервере: ведение персональных счётчиков сообщений для каждого клиента и их сброс при отключении.

### 2. Системное программирование
*Изучение Linux API, работы с процессами, потоками и сокетами.*

* 📁 **[Task6 — Task8](./Task6) — Динамическая память и библиотеки:**
  * **Task6:** Управление динамической памятью.
  * **Task7:** Создание статических библиотек.
  * **Task8:** Создание динамических библиотек.
* 📁 **[Task9 — Task10](./Task9) — Файловая система и процессы:**
  * **Task9:** Работа с файлами через системные вызовы (виртуальная файловая система).
  * **Task10:** Управление процессами.
* 📁 **[Task11 — Task15](./Task11_\(threads\)) — Многопоточность и IPC:**
  * **Task11:** Создание потоков и их синхронизация.
  * **Task12:** Организация связи между процессами через каналы.
  * **Task13:** Передача структурированных данных через очереди сообщений.
  * **Task14:** Обмен данными через разделяемую память.
  * **Task15:** Обработка системных сигналов ОС.
* 📁 **[Task16_1 — Task16_4](./Task16_1) — Сокеты (IPC)**
  * **Task16_1:** Обмен строками между клиентом и сервером с использованием различных семейств сокетов (`AF_LOCAL` / `AF_INET`) и типов (`SOCK_STREAM` / `SOCK_DGRAM`).
  * **Task16_2:** Разработка клиент-серверного приложения для выдачи текущего времени клиенту по 4 шаблонам серверных приложений (простой параллельный сервер, с предварительным созданием (пул) потоков, шаблон «производитель/потребитель» с очередью и мультипротокольный (для обслуживания TCP и UDP клиентов) `select` / **`poll`** / `epoll`).
  * **Task16_3:** Реализация сервера и клиента для широковещательной (`broadcast`) и многоадресной (`multicast`) передачи данных.
  * **Task16_4 (Raw-сокеты):** Разработка UDP-сервера с модификацией строк и кастомных клиентов на raw - сокетах с ручным формированием сетевых заголовков (транспортного уровеня UDP, сетевого уровня IP и канального уровеня Ethernet) и фильтрацией входящих пакетов.

### 3. Встраиваемые системы и разработка модулей ядра Linux
*Разработка программного обеспечения для аппаратных платформ и конфигурация операционной системы.*

* 📁 **[Task17](./Task17_kernel_build) — Сборка ядра Linux:**
  * Конфигурирование параметров ядра через утилиту menuconfig.
  * Компиляция кастомного ядра Linux, сборка модулей и обновление конфигурации загрузчика GRUB.
* 📁 **[Task18](./Task18) — Корневая файловая система:**
  * Компиляция исходного кода ядра Linux и сборка дерева устройств под архитектуру ARM.
  * Создание инициализатора на Си для проверки базовой работоспособности процесса init в эмуляторе QEMU.
  * Конфигурирование, статическая сборка пакета утилит BusyBox под ARM и создание на его базе образа файловой системы initramfs.
  * Запуск системы в эмуляторе, развертывание командной строки и монтирование виртуальной файловой системы.
* 📁 **[Task19](./Task19_openssh) — Кросс-компиляция:**
  * Кросс-компиляция библиотек zlib и OpenSSL под архитектуру ARM.
  * Кросс-компиляция пакета OpenSSH и интеграция исполняемых файлов в файловую системы.
  * Конфигурация системных файлов пользователей и генерация ключей шифрования хоста через ssh-keygen.
  * Настройка изолированной среды доступа и запуск службы sshd внутри эмулятора QEMU.
* 📁 **[Task20_1 — Task20_2](./Task20_1) — Модули ядра Linux:**
  * **Task20_1:** Написание базового загружаемого модуля ядра (test1.ko) и создание символьного драйвера устройства (test2.ko).
  * **Task20_2:** Обмен данными между пространством пользователя и ядром Linux с использованием виртуальных файловых систем `procfs` и `sysfs`.
